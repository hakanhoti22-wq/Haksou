Propriétaire
Mon relais Votre relais Cloudflare garde vos clés cachées. Avec votre code propriétaire, cet appareil a un accès illimité et peut inviter la famille gratuitement.
⚠️ Pour inviter la famille, reliez la base de données à votre relais : Cloudflare → Workers & Pages → votre relais → Settings → Bindings → + Add → KV namespace → nom HAKSOU → Deploy. Puis rouvrez ces réglages.

Installer Haksou

Ajoutez Haksou à votre écran d'accueil : il s'ouvrira comme une vraie app, en plein écran, en un toucher.

Ouvrez d'abord ce lien dans Safari : touchez ⋯ ou ⇱ puis « Ouvrir dans Safari ».

  1. Touchez Partager (en bas de Safari)
  2. Choisissez Sur l'écran d'accueil (faites défiler si besoin)
  3. Touchez Ajouter, puis ouvrez Haksou depuis son icône
