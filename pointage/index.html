Automatisation « Arrivée »

  1. App Raccourcis → Automatisation → + → Arrivée.
  2. Lieu → colle les coordonnées ci-dessus dans la recherche, puis règle le rayon.
  3. Exécuter immédiatement → Suivant → Nouveau raccourci vide.
  4. Action Obtenir le contenu de l’URL → colle l’URL ①.
