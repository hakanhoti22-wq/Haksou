Copie ces deux adresses, elles servent dans les automatisations Raccourcis :
– –
  1. App Raccourcis → onglet Automatisation → + → Arrivée.
  2. Lieu → Choisir → cherche « Marly Innovation Center » (ou ajuste le point), règle le rayon (~150–250 m).
  3. Coche Exécuter immédiatement (et décoche « Notifier » si tu veux) → Suivant.
  4. Nouveau raccourci vide → action Obtenir le contenu de l’URL → colle l’URL arrivée.
  5. Refais pareil avec Départ et l’URL départ.
  6. Réglages iOS → Confidentialité → Service de localisation → Raccourcis : Toujours + Position exacte.
