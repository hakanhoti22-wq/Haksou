Pointage automatique (iPhone)

Méthode simple : 2 automatisations, 1 seule action chacune.
  1. App Raccourcis → onglet Automatisation (en bas) → + → Arrivée.
  2. Lieu → Choisir → écris Marly Innovation Center (ou colle les coordonnées de la carte) → rayon – m → OK.
  3. Coche Exécuter immédiatement → Suivant → Nouveau raccourci vide.
  4. Ajouter une action → cherche URL → touche Obtenir le contenu de l’URL.
  5. Touche le mot bleu URL → colle l’URL ① ci-dessous → OK.
